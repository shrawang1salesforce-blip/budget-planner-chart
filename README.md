# Pocket Budget Planner

A small monthly budget planner built with plain HTML, CSS, and JavaScript. Set a limit for each category, add expenses as they happen, and see how the two compare.

## Run it

Open `index.html` in a browser. Your budgets and expenses are saved in that browser's local storage, so they stay on this device.

The chart uses Chart.js from jsDelivr, so an internet connection is needed to display it. The rest of the planner works without the chart library.
